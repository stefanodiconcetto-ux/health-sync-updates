# EvolMe — aggiornamenti pubblici

Canale pubblico di distribuzione delle APK **EvolMe Phone** e **EvolMe Watch** e del manifest `latest.json`.

Il repository non contiene codice dell'app, profili, esportazioni, misure o dati sanitari. Alcuni nomi di file/endpoint tecnici storici sono conservati esclusivamente per la compatibilità delle versioni già installate; non identificano il marchio corrente.

Non modificare o eliminare gli endpoint in uso senza una prova end-to-end dell'aggiornamento dalla versione pubblica precedente e la verifica della firma.
